# LLM-Powered Code Review Assistant

## Overview
The **LLM-Powered Code Review Assistant** is a production‑ready service that leverages a large language model (LLM) to automatically review Python code, surface potential bugs, style issues, and suggest improvements. The core inference engine runs on PyTorch, while a FastAPI server exposes a clean HTTP API that can be integrated into CI pipelines, IDE extensions, or any custom tooling.

Key features:
- **Context‑aware review** using a fine‑tuned LLM.
- **Batch processing** for multiple files in a single request.
- **Dockerized deployment** for consistent environments.
- **Extensive test suite** with `pytest` to guarantee reliability.
- **OpenAPI schema** automatically generated by FastAPI.

## Prerequisites
- Python 3.11 or newer
- Docker (optional, for containerized deployment)
- An NVIDIA GPU with CUDA 11.8+ **or** CPU‑only inference (slower)
- Access token for the chosen LLM provider (e.g., OpenAI, HuggingFace) – set as `LLM_API_KEY` in the environment.

## Setup (Local Development)

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourorg/llm-powered-code-review-assistant.git
   cd llm-powered-code-review-assistant
   ```

2. **Create a virtual environment**
   ```bash
   python -m venv .venv
   source .venv/bin/activate   # On Windows: .venv\Scripts\activate
   ```

3. **Install dependencies**
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

4. **Configure environment variables**
   ```bash
   export LLM_API_KEY="your-llm-api-key"
   export MODEL_NAME="gpt-4o-mini"   # Example; adjust to your model
   ```

5. **Run the FastAPI server**
   ```bash
   uvicorn src.main:app --host 0.0.0.0 --port 8000 --reload
   ```

   The API documentation is automatically available at `http://localhost:8000/docs`.

## Running with Docker

1. **Build the image**
   ```bash
   docker build -t llm-code-review-assistant:latest .
   ```

2. **Run the container**
   ```bash
   docker run -d \
     -p 8000:8000 \
     -e LLM_API_KEY="your-llm-api-key" \
     -e MODEL_NAME="gpt-4o-mini" \
     --name llm-review-assistant \
     llm-code-review-assistant:latest
   ```

   The service will be reachable at `http://localhost:8000`.

## API Usage

### Endpoint: `/review`
**Method:** `POST`  
**Content‑Type:** `application/json`

#### Request payload
```json
{
  "files": [
    {
      "path": "example.py",
      "content": "def add(a, b):\n    return a + b"
    },
    {
      "path": "utils/helpers.py",
      "content": "# helper functions ..."
    }
  ],
  "language": "python"
}
```

#### Response payload
```json
{
  "review_id": "c3f1e9b2-7a4d-4f8b-9a2e-5d2f1c9a6b7c",
  "issues": [
    {
      "file": "example.py",
      "line": 1,
      "severity": "info",
      "message": "Consider adding a docstring for the function `add`."
    },
    {
      "file": "example.py",
      "line": 2,
      "severity": "warning",
      "message": "Missing type hints for parameters `a` and `b`."
    }
  ],
  "summary": "2 issues found across 2 files."
}
```

You can test the endpoint locally with `curl`:

```bash
curl -X POST http://localhost:8000/review \
  -H "Content-Type: application/json" \
  -d @sample_payload.json
```
